# OpenAI Ads

Use this for contextual conversational placements. Combine it with the shared
method; use `egbe-os-openai-ads` for available formats, context fields, lifecycle
and measurement limits.

## Fit the conversational need

Explain why this offer helps in the intended context. Context hints describe
relevance; they are not keywords with demonstrated search volume. Distinguish
the useful offer from the CTA and keep the destination consistent with both.

For a chat card, image, title and body should complement each other: use a clear,
crop-safe focal point, a concrete benefit and a next step that makes sense from
that conversation.
